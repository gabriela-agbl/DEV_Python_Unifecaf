# Aula 06 — pacote único de scripts

## O que este pacote contém

- dez pastas independentes, uma para cada exercício prático de A06-E0 a A06-E9;
- os mesmos enunciados e prompts PACIF do template corrigido;
- códigos, dados e comandos necessários para trabalhar em Windows, macOS ou Linux;
- um arquivo único para registrar as respostas;
- nenhum gabarito.

## Como começar

1. Extraia o ZIP.
2. Abra a pasta `Aula_06_Scripts_Alunos` inteira no VS Code.
3. Abra `EXERCICIOS_E0_A_E9.md` e `RESPOSTAS.md`.
4. Entre em `exercicios/A06-E0`.
5. Trabalhe na ordem E0, E1, E2, E3, E4, E5, E6, E7, E8 e E9.

## Regra importante

Cada pasta é independente. Não copie automaticamente uma solução de uma pasta posterior. Complete as lacunas, execute e registre a saída real antes de avançar.

## Comandos

- Windows: use os arquivos `executar.ps1` quando existirem.
- macOS/Linux: use os arquivos `executar.sh` quando existirem.
- Se não houver script de execução, siga o comando mostrado em `ENUNCIADO.md`.
